Runs a local HTTP server on http://localhost:8000
Has:
✅ Text input box
✅ Submit button (saves prompt)
✅ Show Prompts button (displays saved prompts)
✅ Clear button (clears textbox)
✅ Audio Record Start
✅ Audio Record Stop
✅ Audio Play
✅ Audio Show

Stores prompts in a small SQLite database
Keeps only the latest 10 prompts and Audio records.
